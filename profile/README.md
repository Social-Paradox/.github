# Social Paradox

**Miernik CO2, który mówi, kiedy i jak długo wietrzyć.**

W małych pokojach — akademikach, wynajmowanych mieszkaniach — powietrze szybko robi się
duszne, a człowiek tego nie czuje. Nasze urządzenie mierzy CO2, temperaturę i wilgotność,
a aplikacja na telefon podpowiada, kiedy otworzyć okno i na jak długo.

| | |
|---|---|
| **Urządzenie** | M5StickC Plus2 + Sensirion SCD41 |
| **Aplikacja** | Flutter — iOS i Android, połączenie przez Bluetooth Low Energy |
| **Projekt** | hackathon GrowUp |
